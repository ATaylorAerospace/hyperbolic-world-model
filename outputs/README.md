# outputs/

Gitignored except for this file. Every table and figure in the report is regenerated from the
contents of this directory by `scripts/make_report.sh`; nothing in the report is hand-edited.

```text
outputs/
├── smoke/                      # written by scripts/run_smoke.sh (CI runs this)
├── baseline_euclidean/
├── poincare_sweep/             # one sub-directory per curvature value
├── lorentz_sweep/
│   └── curvature=-1.0/
│       ├── metrics.json        # {task: {metric: value}} in the model's native geometry
│       ├── rollout_curves.csv  # error vs horizon
│       └── config.yaml
└── report/                     # generated by make_report.py
    ├── tables/*.md
    └── figures/*.png
```
