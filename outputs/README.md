# outputs/

Gitignored except for this file. Every table and figure in the report is regenerated from the
contents of this directory by `scripts/make_report.sh` (one command, deterministic: the same
`outputs/` gives byte-identical files); nothing in the report is hand-edited.

```text
outputs/
├── smoke/                      # written by scripts/run_smoke.sh (CI runs this)
├── baseline_euclidean/
├── poincare_sweep/             # one sub-directory per (curvature, dimension, seed)
├── lorentz_sweep/
│   └── geometry=lorentz,K=-1.0,dim=64,seed=0/
│       ├── metrics.json        # geometry, curvature, latent_dim, seed + {task: {metric: value}} in the model's native geometry
│       ├── config.yaml         # fully resolved Hydra config
│       ├── latent_rollout_curves.csv               # error vs horizon (+ static baseline, normalised)
│       ├── hierarchy_reconstruction_curves.csv     # dist0 vs tree depth
│       ├── long_horizon_consistency_curves.csv     # latent / embedded / encoder / pixel divergence vs horizon
│       └── compositional_generalization_curves.csv # seen vs unseen error vs horizon
└── report/                     # generated by make_report.py
    ├── README.md               # index of everything below
    ├── tables/
    │   ├── results.md                                  # every (run, task, metric)
    │   ├── summary.md                                  # mean ± std over seeds per configuration
    │   ├── <task>__<metric>__curvature_sweep.md        # (geometry, K) x latent_dim grid, per swept metric
    │   ├── best_curvature_vs_euclidean.md              # best swept curvature vs the flat baseline, one-std rule
    │   └── dimension_efficiency.md                     # log2 AUC and dimension to reach the Euclidean baseline
    └── figures/
        ├── <task>__<metric>__vs_curvature.png          # per swept metric
        ├── <task>__<metric>__vs_dimension.png          # per metric with more than one dimension
        └── <task>__curves.png                          # every <task>_curves.csv overlaid, seeds averaged
```
